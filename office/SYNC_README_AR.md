# مزامنة المكتب الافتراضي المشفرة

هذه الآلية لا تستضيف قاعدة بيانات الشركة ولا تكشفها. تستخرج من نسخة الحالة المشفرة لقطة محدودة فقط، ثم تشفر اللقطة بمفتاح مستقل وتنشر **النص المشفر وحده** في فرع `office-sync`. لا تكتب في `main` أو `state`، ولا تغيّر دورة Telegram.

## محتوى اللقطة
- الموظفون والأدوار وحالة النشاط.
- الإدارات وعلاقاتها.
- عناوين المهام وحالاتها وأولوياتها.
- نوع الموافقة وحالتها وتاريخها فقط، دون محتوى الطلب.
- حالات التشغيل وعدد الخطوات، دون سجل التفكير أو الملاحظات.

لا تتضمن اللقطة نصوص الذاكرة أو المحادثات أو نتائج المهام أو محتوى الموافقات أو الأسرار.

## إعداد المفتاح مرة واحدة
أنشئ مفتاحًا عشوائيًا محليًا بطول 32 بايت على الأقل، واحتفظ بنسخة منه في مدير كلمات مرور. لا ترسله في المحادثة ولا تضعه في ملفات Git.

في Termux:
```bash
python -c 'import secrets; print(secrets.token_urlsafe(48))'
```

انسخ الناتج محليًا، ثم افتح مستودع GitHub:
Settings → Secrets and variables → Actions → New repository secret

اسم السر:
`OFFICE_SYNC_PASS`

القيمة: المفتاح الذي أنشأته محليًا. لا تعد استخدام `STATE_PASS`.

## توليد اللقطة
من Actions شغّل يدويًا:
`Encrypted virtual office snapshot`
واختر الفرع `virtual-office-foundation`.

يتطلب ذلك وجود السرّين `STATE_PASS` (الموجود أصلًا لاستعادة الحالة) و`OFFICE_SYNC_PASS`. إذا غاب أحدهما يتوقف التصدير دون نشر أي ملف.

## تشغيل المكتب محليًا على Android / Termux
نزّل نسخة المستودع على الجهاز، ثم أدخل المفتاح في جلسة Termux دون كتابته في الأمر:
```bash
read -rsp "مفتاح مزامنة المكتب: " OFFICE_SYNC_PASS
export OFFICE_SYNC_PASS
echo
bash office/sync.sh
```

سيحمّل السكربت الملف المشفر من فرع `office-sync`، ويفكّه داخل مجلد مؤقت بصلاحيات خاصة، ويتحقق من بنيته، ثم يشغّل خادم القراءة فقط. عند الإغلاق يحذف النسخة المؤقتة. يتولد رمز API محلي جديد عند كل تشغيل؛ أدخله في واجهة المكتب.

## حدود مهمة
- اللقطة لا تتحدث تلقائيًا؛ شغّل workflow يدويًا بعد الحاجة إلى تحديثها.
- لا تجعل فرع `office-sync` خاصًا ببيانات حساسة: محتواه مشفر، لكن بياناته الوصفية (حجم الملف ووقت التحديث) ظاهرة.
- احمِ مفتاح `OFFICE_SYNC_PASS` كما تحمي كلمة مرور مهمة. من يملك المفتاح وملف اللقطة يستطيع قراءة البيانات المحدودة.
- لا تستخدم هذا المسار عبر شبكة عامة. الخادم يستمع على `127.0.0.1` فقط.
