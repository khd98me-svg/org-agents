# مزامنة المكتب الافتراضي المشفرة

هذه الآلية لا تستضيف قاعدة بيانات الشركة ولا تكشفها. تستخرج من نسخة الحالة المشفرة لقطة محدودة فقط، ثم تشفر اللقطة بمفتاح مستقل، وتضيف HMAC-SHA256 بمفتاح مشتق مستقل للتحقق من سلامة النص المشفر قبل فكّه، وتنشر الملف المشفر وبصمة التحقق فقط في فرع `office-sync`. لا تكتب في `main` أو `state`، ولا تغيّر دورة Telegram.

## محتوى اللقطة
- الموظفون والأدوار وحالة النشاط.
- الإدارات وعلاقاتها.
- عناوين المهام وحالاتها وأولوياتها.
- نوع الموافقة وحالتها وتاريخها فقط، دون محتوى الطلب.
- حالات التشغيل وعدد الخطوات، دون سجل التفكير أو الملاحظات.

لا تتضمن اللقطة نصوص الذاكرة أو المحادثات أو نتائج المهام أو محتوى الموافقات أو الأسرار.

## إعداد المفتاح مرة واحدة — خطوات GitHub بالتفصيل

نفّذ الخطوات التالية من المتصفح، ويمكنك استخدام متصفح الهاتف:

### أولًا: إنشاء المفتاح في Termux

1. افتح Termux.
2. الصق الأمر التالي واضغط Enter:

```bash
python -c 'import secrets; print(secrets.token_urlsafe(48))'
```

3. سيظهر نص طويل عشوائي. انسخه واحتفظ به مؤقتًا في مكان آمن؛ ستلصقه في GitHub بعد قليل.
4. لا ترسل هذا النص في محادثة ChatGPT أو Telegram، ولا تضعه داخل أي ملف بالمستودع.

### ثانيًا: إضافة المفتاح إلى GitHub

1. افتح المستودع: https://github.com/khd98me-svg/org-agents
2. افتح تبويب **Settings** الخاص بالمستودع. إذا لم يظهر، تأكد أنك مسجل الدخول بالحساب الذي يملك صلاحية إدارة إعدادات المستودع.
3. من القائمة الجانبية اختر **Secrets and variables** ثم **Actions**.
4. اضغط **New repository secret**.
5. في خانة **Name** اكتب الاسم حرفيًا:

   `OFFICE_SYNC_PASS`

6. في خانة **Secret** الصق النص الذي أنشأته في Termux.
7. اضغط **Add secret**.

بهذا تكون أضفت السر؛ لن يعرض GitHub قيمته مرة أخرى بعد الحفظ. لا تنشئ سرًا باسم مختلف، ولا تستخدم `STATE_PASS` بدلًا منه؛ فهما مفتاحان منفصلان.

**تنبيه:** هذه الخطوات تضيف السر فقط، ولا تشغّل المزامنة تلقائيًا. تشغيلها موضح في القسم التالي.

## توليد اللقطة
من Actions شغّل يدويًا:
`Encrypted virtual office snapshot`
واختر الفرع `virtual-office-foundation`.

يتطلب ذلك وجود السرّين `STATE_PASS` (الموجود أصلًا لاستعادة الحالة) و`OFFICE_SYNC_PASS`. إذا غاب أحدهما يتوقف التصدير دون نشر أي ملف.

## تشغيل المكتب محليًا على Android / Termux
نزّل نسخة المستودع على الجهاز، ثم أدخل المفتاح في جلسة Termux دون كتابته في الأمر:
```bash
read -rsp "مفتاح مزامنة المكتب: " OFFICE_SYNC_PASS
export OFFICE_SYNC_PASS
echo
bash office/sync.sh
```

سيحمّل السكربت الملف المشفر وبصمة HMAC من فرع `office-sync`، ويتحقق من البصمة قبل فك التشفير. عند فشل التحقق يتوقف دون فك الملف. بعد ذلك يفكّه داخل مجلد مؤقت بصلاحيات خاصة، ويتحقق من بنيته، ويصفّي الخادم الحقول عبر قائمة مسموحة قبل عرضها، ثم يشغّل خادم القراءة فقط. عند الإغلاق يحذف النسخة المؤقتة. يتولد رمز API محلي جديد عند كل تشغيل؛ أدخله في واجهة المكتب.

## حدود مهمة
- اللقطة لا تتحدث تلقائيًا؛ شغّل workflow يدويًا بعد الحاجة إلى تحديثها.
- لا تجعل فرع `office-sync` خاصًا ببيانات حساسة: محتواه مشفر، لكن بياناته الوصفية (حجم الملف ووقت التحديث) ظاهرة.
- احمِ مفتاح `OFFICE_SYNC_PASS` كما تحمي كلمة مرور مهمة. من يملك المفتاح وملف اللقطة يستطيع قراءة البيانات المحدودة.
- لا تستخدم هذا المسار عبر شبكة عامة. الخادم يستمع على `127.0.0.1` فقط.
