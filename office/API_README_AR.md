# تشغيل جسر المكتب الافتراضي

## ما أُضيف

`server.py` خادم Python محلي للقراءة فقط. يعرض:
- `GET /api/health`
- `GET /api/snapshot`: الموظفون، الإدارات، المهام، الموافقات المعلقة، وآخر التشغيلات.

كل مسارات API تتطلب:
`Authorization: Bearer <OFFICE_TOKEN>`

طلبات POST وPUT وDELETE مرفوضة دائمًا. قاعدة SQLite تُفتح بوضع القراءة فقط. وعند استخدام ملف لقطة، لا يقبل الخادم إلا قائمة حقول محددة؛ تُحذف أي حقول إضافية مثل payload أو result أو history أو thought قبل إرجاع البيانات.

## مسار مزامنة الإنتاج المشفّر

1. يقرأ Workflow المسمى `Encrypted virtual office snapshot` حالة الشركة من فرع `state` باستخدام `STATE_PASS`.
2. يصدر `office/export_snapshot.py` حقول لوحة المكتب المحدودة فقط.
3. يشفّر JSON باستخدام AES-256-CBC وPBKDF2.
4. ينشئ HMAC-SHA256 بمفتاح مشتق مستقل للتحقق من سلامة الملف المشفر.
5. ينشر `snapshot.enc` و`snapshot.hmac` فقط إلى فرع `office-sync`. لا ينشر قاعدة البيانات أو JSON الصريح.

قبل تشغيل Workflow لأول مرة، يجب إعداد GitHub Actions Secret باسم `OFFICE_SYNC_PASS` بقيمة عشوائية قوية لا تقل عن 32 حرفًا. لا تضع القيمة في الملفات أو المحادثة ولا ترسلها لأي شخص. يبقى `STATE_PASS` سرًا منفصلًا كما هو.

تشغيل Workflow يدويًا:
GitHub → Actions → Encrypted virtual office snapshot → Run workflow → اختر `virtual-office-foundation`.

## تشغيل المكتب محليًا في Termux

بعد نجاح Workflow وإنتاج ملفات فرع `office-sync`، نفّذ من مجلد المشروع:

```bash
read -rsp "Office sync passphrase: " OFFICE_SYNC_PASS; echo
export OFFICE_SYNC_PASS
bash office/sync.sh
```

أدخل قيمة `OFFICE_SYNC_PASS` محليًا فقط. يتحقق السكربت من HMAC قبل فك التشفير، ثم يتحقق من بنية اللقطة، ويشغّل الخادم على `127.0.0.1:8765`. سيظهر رمز وصول مؤقت؛ أدخله في خانة رمز الوصول داخل الواجهة. لا تشارك الرمز، ولا تفتح المنفذ على الإنترنت.

## الحدود الحالية

- المزامنة ليست تلقائية بعد كل دورة تشغيل؛ يلزم تشغيل Workflow يدويًا لتحديث اللقطة.
- الخادم يعمل على جهازك ما دام Termux والعملية يعملان.
- واجهة المكتب لا تنفّذ حاليًا إنشاء المهام أو الموافقات أو إدارة الموظفين؛ واجهة العرض الحالية للقراءة فقط.
- لا توقف Telegram ولا تغيّر مسار تشغيل الشركة قبل اختبار عملي وموافقة صريحة.

## فحوص الأمان

- قاعدة البيانات تُفتح بوضع القراءة فقط.
- لا تصدر نتائج المهام أو نصوص الموافقات أو الذاكرة أو سجل التفكير.
- تُصفّى اللقطات عبر قائمة حقول مسموحة.
- يُتحقق من HMAC قبل فك التشفير.
- الخادم محصور في loopback ويتطلب رمزًا بطول 32 حرفًا على الأقل.
